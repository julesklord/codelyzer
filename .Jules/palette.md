## 2026-09-09 - Added ARIA label and title to icon-only folder toggle button
**Learning:** Found that custom icon-only toggle buttons using generic tags (e.g., `span`) often lack accessible names, making them invisible or confusing to screen reader users. Adding both `aria-label` and `title` improves accessibility for screen readers while also providing a visible tooltip on hover for sighted users.
**Action:** Always verify that interactive elements containing only visual unicode characters or icons include an explicit `aria-label` and consider pairing it with a `title` attribute for broader UX benefit.
