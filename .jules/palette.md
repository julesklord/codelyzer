## 2026-09-16 - Add aria-label and title to icon-only buttons
**Learning:** When using generic tags like `span` or `div` for custom icon-only toggle buttons containing only visual unicode characters (e.g., '▶' in TreeNode), they lack implicit semantic meaning and context for screen readers. Simply assigning `role="button"` is insufficient. Adding an `aria-label` provides the necessary accessible name for assistive technologies, ensuring the purpose of the element is properly conveyed. Simultaneously, adding a `title` attribute provides a native browser tooltip on hover for sighted users, improving micro-UX.
**Action:** Always include an explicit `aria-label` (e.g., 'Expand folder') on custom icon-only elements that use visual unicode characters or custom SVGs without inner text. Accompany it with a matching `title` attribute to ensure parity in experience for both screen reader and sighted users.
